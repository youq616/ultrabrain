连接你的个人记忆

在服务器上读取启动命令提示的私有令牌文件，将令牌粘贴到此处。它只保存在当前页面内存中，不写入浏览器存储。

远程 Linux 服务请通过 SSH 隧道访问；不要把这个管理端口暴露到公网。此令牌不是模型 API Key，也不是 MCP 令牌。

待确认记忆

只查询本机所有者可见且已启用的记忆，不调用模型、不保存任务为记忆。其他 MCP 身份的结果可能不同。字面匹配不是语义搜索；可用空格分隔关键词。

任务最多 4096 UTF-8 字节。修改条件或撤回同意会清除旧结果并取消等待；已到达服务器的查询不能撤回。需要纠错时，点击结果中的“核对最新记录”，重新读取版本后再明确编辑并确认。

按完整记忆 ID 读取当前可见版本，不调用模型、不修改内容。自己的候选及归档记录仍可核对；其他人的记录只有仍在有效共享范围内才可见。ID 不是授权凭据。

从召回卡片点击“核对最新记录”会重新读取，不直接编辑旧预览。核对不会改动右侧未保存的内容；明确点击“编辑”才填入所读版本。

只展示当前身份可见的记录。

新建候选记忆

保存不会自动确认真实性。编辑已有记忆后，它会重新进入待确认状态。

排队整理会先保存一份私有原文，模型另行明确运行。编辑已有记录时不能排队新原文。

共享记忆只有明确激活后才对同源其他身份可读。Agent 名称不是身份认证。

人工核对版本差异

这里只读查询，不保存草稿。请逐项核对内容、项目、可见性、来源、重要性和可信度估计。采用新基准会保留草稿全部字段，不自动合并他人改动。修改草稿会清除本次对照；完成修改后可再次读取。

导入个人文本文件


只导入你在这个表单里明确选择的 UTF-8 文本文件（TXT / MD / JSON / CSV / LOG，≤128 KiB）。文件按原始字节保存，不会自动执行或解析其中内容，也不会自动排队整理。超过上限或编码非法的文件会被整体拒绝，不会截断保存。JSON/CSV 仅作为不可信文本保存。
