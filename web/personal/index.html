连接你的个人记忆

在服务器上读取启动命令提示的私有令牌文件，将令牌粘贴到此处。它只保存在当前页面内存中，不写入浏览器存储。

远程 Linux 服务请通过 SSH 隧道访问；不要把这个管理端口暴露到公网。此令牌不是模型 API Key，也不是 MCP 令牌。

新建候选记忆

保存不会自动确认真实性。编辑已有记忆后，它会重新进入待确认状态。

排队整理会先保存一份私有原文，模型另行明确运行。编辑已有记录时不能排队新原文。

共享记忆只有明确激活后才对同源其他身份可读。Agent 名称不是身份认证。

有一次提交尚未确认

不要重新生成内容或新的事件编号。下面的重试会使用相同请求。刷新或关闭页面会丢失内存中的待确认请求；可以先将其保存到本机。
