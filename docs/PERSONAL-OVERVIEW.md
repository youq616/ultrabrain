# 记忆库运行概览

一个明确读取、当前身份隔离的元数据概览。入口在个人管理台的“记忆库运行概览”；打开面板不会查询，点击“读取／刷新概览”才读取一次。它不启动整理、不调用模型、不读取正文或自动轮询，不是数据库备份、磁盘健康检查或真实性认证。

## 四类统计

记忆：全部记录、待确认、已启用、已归档，细分“已启用且直接来源仍有效”“已启用但直接来源失效”“待确认且直接来源失效”，并显示其中的文档片段数。无结构化引用的记录沿用现有有效性规则；这不是对正文指纹重新计算，也不是递归依赖审计。候选原文和文档片段本身包含在总数中，不能把总数等同于已确认知识数。

任务：等待整理、处理中、已完成、失败、已取消或来源失效。处理中按同一数据库观察时刻分为租约尚未到期／已到期；失败中细分尝试次数低于当前服务端上限的数量。**租约到期和次数未达上限都不是重试授权。** 要执行、恢复或取消，仍须进入任务列表重新核对、明确确认，并接受原有租约、次数和计费规则。

文档：使用中与已归档数量；Agent：当前身份登记的标签数量。Agent 标签不是已安装软件或认证主体的证明。所有统计包含当前身份拥有的所有项目及全局记录，不包括他人共享记录或旧的无所有者记录。

五个跳转按钮仅打开已有待审、当前记忆、任务、文档或Agent列表，保留该列表已有筛选和未保存草稿。那些列表可能显示同源共享记录，或保留项目/状态筛选，因此不承诺它们的数量与本面板相同。统计不会传递修改权限或自动选择一条记录。

## 接口合同

兼容模式 MCP 新增只读工具 `ultra_personal_overview`，管理台固定 API 操作为 `overview`，均接受且仅接受：

```json
{"request_id":"11111111-1111-4111-8111-111111111111"}
```

每次读取应使用新 UUID；它只绑定这一次响应，不是幂等事件、历史结果存储或授权凭据。来源和主体来自认证上下文，不能传入 source_id、actor_key、project_id、limit 或其他选择器。工具需要现有 read 权限；没有增加写授权。受管企业工具白名单不扩展；兼容客户端 READ_TOOLS 允许转发该只读工具，但不将其加入旧服务器的必需工具集。

成功响应的固定字段：format=`ultrabrain-personal-overview-v1`、scope=`owned-all-projects`、source_id、request_id、observed_at（UTC毫秒字符串）、read_only=true、model_calls=0、trust=`untrusted-memory-metadata`，以及 memories/jobs/documents/agents 四个统计对象。源码 `personal-overview-contract.mjs` 是浏览器与服务端共享的唯一形状/分区校验定义；数量必须是0至2147483647的整数，状态合计、有效性子集与租约分区必须自洽。成功结果使用冻结副本。程序化调用只接受数据属性：拒绝 getter/setter、隐藏或 Symbol 多余字段，避免验证通过后复制出不同值；不执行来路不明的字段访问器。

返回内容不包括正文、引文、文件内容或路径、Agent标签/能力明细、项目名、任务/记忆ID、认证actor_key、错误日志或模型配置。source_id及计数仍属于私有运行元数据，不应公开。无需用户同意正文读取，因为此操作没有请求正文；点击读取本身是明确查询动作。

## 一致性、限制与失败语义

服务端在只读事务中使用一条聚合 SELECT 汇总四类对象，共用 statement_timestamp 和该语句快照。使用事务局部5秒语句超时、1秒锁等待超时，无跨网络长事务或所有者写锁。全部子查询都绑定同一 source/principal，直接来源检查复用已有 PERSONAL_DERIVATION_CURRENT。上下文在执行前、数据库返回后和驱动字段物化／契约验证完成后再次检查。

不先截断原记录再计数；超时、超出整数范围或非法分区会整体失败，不输出部分总数。这里的限制不是数据库全量盘扫描性能保证，也不是客户端到服务端5秒端到端硬期限；外层网络和调度仍有各自的边界。

打开未读取、查询失败、取消、权限变化都不能显示成“空库”。只有完整校验通过的全零结果才表示本次所见范围内没有记录。统计是某次观察，不是实时服务健康状态；原记录和租约之后仍可能改变。

关闭、导航、刷新、锁定或其他独立核对工作区入口会使旧结果和正在等待的响应失效。每次异步交付和跳转再次检查会话、来源、视图、导航版本、busy/pending与面板状态，迟到失败不能覆盖新的成功结果。取消等待不会撤回已到达数据库的只读查询；清空引用不承诺内存安全擦除。

## 验证与阶段状态

本地入口：`node --test test/personal-overview*.test.mjs`；覆盖共享合同、生产SQL适配器边界、实际页面脚本以及真实Node HTTP服务器。后两类测试分别使用合成DOM/传输和合成数据库适配器，不是实际PostgreSQL证明。

`test/personal-overview-browser.py --offline` 在真实Chromium中加载当前HTML、CSS及全部六份页面脚本，以合成传输和计数进行交互。测试不是在线HTTP或数据库验收，也不绕过浏览器导航限制。

`test/personal-overview-http-browser.mjs` 通过真实认证HTTP和CSP加载生产页面，以合成数据库测试同一套浏览器交互。单独的 smoke 工作流运行该层；不将它误报为 PostgreSQL 验收。

`test/personal-overview-integration.mjs` 已接入原隔离CI后置步骤：实际PostgreSQL、原生dispatch、官方SDK stdio目录/调用、真实管理台HTTP/Chromium、当前/失效来源和租约分类、主体/来源隔离、六张应用表只读指纹检查。准备阶段包括显式合成写入及三次注入生成器，零外部模型。本地容器没有本项目的 PostgreSQL/Bun 上游运行时，实际执行状态以对应提交的 CI 为准，不能以脚本存在代替结果。

本模块是开发候选，不是生产发布。代码、自查、真实CI及独立代理复审是分开的门禁；每次修改后均须核对完整最终提交。状态及首败记录见 `docs/reviews/personal-overview/README.md`。不覆盖并行开发、不合并 main、不部署用户主机。
