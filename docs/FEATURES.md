# 功能覆盖与完成标准

Ultrabrain 以锁定版本的 GBrain 业务引擎为运行基础，新增自己的产品层。OpenViking 目前作为锁定的参考上游，**不是同时运行的第二套记忆服务，也不是已经完成全功能移植**。

## 状态用语

- **已实现**：仓库有可执行实现和对应测试；是否在某次提交通过，以该提交的 CI 为准。
- **继承**：通过锁定的 GBrain 原生 CLI/MCP 调用；不表示每个上游功能已在 Ultrabrain 中独立验收。
- **部分实现**：有明确可用子集，同时说明边界。
- **待实现/验收**：不能在宣传、版本说明或健康检查中写成已完成。

## 覆盖表

| 能力 | 处理方式 | 当前边界与验收位置 |
|---|---|---|
| 原生 PostgreSQL 本地部署 | 已实现 | 从锁定源码编译到用户私有目录；独立本地进程，不要求外部数据库，不使用 Docker Hub。`scripts/postgres.py`、CI bootstrap。 |
| pgvector | 已实现 | 随 PostgreSQL 编译安装；锁定源码。升级二进制不等于升级数据库中的 extension SQL 版本。 |
| 页面增删改查、版本与软删除恢复 | 继承并封装 | `ultra_write/read/delete` 调用原生 operations；完整替换不是 JSON Patch，不提供未实现的 compare-and-swap。真实数据库和 HTTP 测试。 |
| 统一上下文地址 | 已实现 | `ultra://source/path`；NFC、原生小写 slug 约定、目录边界、危险路径和编码拒绝。 |
| L0/L1/L2 | 部分实现 | L0/L1 是明确标注的 UTF-8 前缀摘要；L2 为原文。不是 OpenViking 的完整语义摘要管线。 |
| 目录浏览 | 部分实现 | 基于授权页面的虚拟目录；有扫描上限和实时 offset，可能重复目录，不能假装完整快照。 |
| 混合检索 | 继承 | 使用原生 search；模型与向量能力取决于实际配置。无 API key 的集成测试不证明向量召回效果。 |
| 层级辅助检索 | 部分实现 | 原生候选结果上的目录辅助重排；目录过滤位于候选获取之后，不等于 OpenViking 完整递归目录检索。 |
| 上下文预算 | 已实现 | 以 UTF-8 字节计算完整 evidence 数组，包括 JSON 转义与元数据；可截短正文保留高位候选。不是模型 token 数，外层 envelope/trace 不在预算内。 |
| 检索轨迹 | 已实现 | 返回候选原始排名、目录分支、重排分数和时间；不声称穷尽召回。 |
| 会话保存与提取 | 部分实现 | `ultra_commit_session` 保存显式提交的 transcript，再调用原生事实提取。无模型时明确 `needs_model`，不伪造提取成功。 |
| 会话幂等与恢复 | 已实现，有边界 | source + actor + session + event 回执、内容冲突检测、租约与显式重试。至少一次，**不是事务性 exactly-once**。 |
| Agent 生命周期接入 | 已实现于 `src/agent-memory.mjs` | 在调用方接入回调后，先检索、再生成、显式授权后保存。不会自动读取浏览器历史、未接入的 Agent 或本地工作目录。 |
| MCP stdio | 已实现 | 通过 preload 注册扩展，再启动原生 CLI 入口。真实 initialize、tools/list、tools/call 测试。 |
| MCP Streamable HTTP | 已实现 | 使用上游传输、鉴权和 SDK；只读、跨 source 拒绝、private 可见性、live token revocation 测试。 |
| 身份、授权与目录写限制 | 继承并适配 | 保留原始 operation context；仅审计过的 CRUD 包装加入原生目录写白名单；广域事实提取不授予目录绑定客户端。 |
| 知识图谱、事实纠正/撤回、技能、任务等 | 继承，需逐项产品验收 | 上游 CLI/operations 保留，不复制第二份数据库实现。不表示这些功能的所有配置和外部依赖已完成端到端验证。 |
| Linux 服务管理 | 部分实现 | 生成 user-systemd 单元，默认仅输出、不启用；MCP 绑定 loopback。CI 检查单元语法，不能替代目标主机的开机、崩溃与重启演练。 |
| 健康检查 | 已实现 | 检查本地运行绑定、账号权限、版本、扩展、schema 和工具注册；不调用模型、不输出记忆/密码。 |
| 数据库备份与隔离恢复 | 已实现，有边界 | 自定义格式 dump、SHA-256、INCOMPLETE 拒绝、新数据库恢复和指纹校验。**不含模型密钥、附件文件和源仓库**。 |
| 上游更新监测 | 已实现 | 原作者与 fork 分别检查；完整 SHA 锁定；annotated tag 解引用到 commit；报告错误不当作成功。 |
| 更新候选与发布 | 部分实现 | 独立候选分支、许可证变更提示、CI、备份恢复门槛；没有自动理解/移植任意上游功能的承诺。 |
| PostgreSQL 同主版本二进制切换 | 已实现 | 不可变运行目录，停止后显式 activate；构建不覆盖正在使用的运行目录。 |
| PostgreSQL 跨主版本升级 | 待实现/验收 | 当前明确拒绝直接切换。需要单独的 pg_upgrade 或新集群逻辑恢复演练。 |
| OpenViking 数据完整迁移 | 待实现 | 尚无保留全部 URI、权限、关系、会话和资源元数据的无损迁移器。 |
| OpenViking 全量解析器、多模态、语义摘要、记忆策略 | 待实现/验收 | 尚未完成对所有上游接口及配置组合的功能等价。 |

## 发布完成标准

某次集成版本可发布，需要同一提交的单元、运维、原生 PostgreSQL、MCP stdio、HTTP 鉴权、备份恢复与运行目录切换测试通过，并保留证据。

“包含双方全部功能”的完成标准更高：必须列出两个锁定上游的公共 CLI/API/MCP 与资源类型，逐项映射、实现并提供迁移与功能验收证据。当前尚未达到该标准。
