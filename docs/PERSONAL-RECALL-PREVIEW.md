# 管理台任务召回预览

个人管理台新增「任务召回预览」视图，复用已经存在的认证 `context` 操作及统一个人记忆排序合同。它是本机所有者的只读检查工具，不新增 MCP 工具、模型、数据库表、排序算法或权限。

## 使用

在既有个人管理台连接后进入「任务召回预览」，填写任务或关键词、可选项目、条数和响应字节预算。每次条件变化后重新勾选同意并点击「预览本次召回」。打开视图、输入文字或点击普通刷新都不会自动发送任务。

任务最多 4096 UTF-8 字节，超限整体拒绝，不截断中文或否定词。当前规则按 Unicode 空白分词、仅折叠 ASCII 大写、按字面重合与重要性排序；可用空格分隔关键词，不能当作语义搜索。项目留空只查询全局，填写则包含全局及所选项目；与记忆编辑表单的项目字段分离。可选上限为 5/10/20 条及 2048/6000/8192 字节。字节不等于 token。

结果显示实际返回顺序、完整记忆正文、ID、版本、内容 SHA-256、来源/原文引用和调用方置信度估计；不自行生成解释分或把排序变成真实性证明。只接收有效的 active 条目、当前来源、合法项目和所有权/显式共享标记，拒绝失效派生或不匹配的内容哈希。界面仅使用 textContent，不执行记忆里的 HTML。

预览卡片没有修改/确认/归档按钮。需纠错时，在「当前记忆」按显示的 ID 核对后编辑；原来的编辑→候选→确认流程不变。此预览使用 Linux 本机所有者身份，不能宣称等于其他认证主体、远端客户端或项目 Agent 实际收到的上下文。

## 预算与空结果

沿用数据库先排名取最多 100 条候选，再按条数与序列化字节预算保留整条的规则。界面显示实际完整上下文响应的字节数和 dropped；dropped 仅统计已取候选窗口内舍弃的条目，不统计数据库里所有遗漏项。外层 HTTP 包装、界面说明和下载包装不计入该上下文字节数。没有截断正文，也不返回“覆盖全部”的承诺。

空结果是一次成功但有限的召回，不代表库为空、没有相关事实或模型必须弃答。请求失败和回执异常不会被显示成成功空列表。

## 授权、取消与导出

只在显式提交且勾选同意时发送任务。它不将任务作为新记忆保存，不创建事件或整理任务，不自动调用模型；不保证主机或网络的连接统计/日志不存在。任务只留在当前表单内存中，本功能不写浏览器存储，表单禁用自动填充；锁定管理台清除任务和项目输入。

输入条件变化、撤销同意、取消、刷新、离开视图或锁定页面都会使本次结果失效，并取消等待。冻结任务/项目/预算、来源和会话；响应及内容哈希验证之后再次比对，旧请求不得覆盖更新请求或重新填充已经锁定的页面。脚本绕过事件直接改变条件时，最终比对也会拒绝变化。已到服务器的读取不能被撤回，取消不声称数据库操作被回滚。没有自动重试。

「导出当前页」仅在成功且尚未失效的预览上可用，导出完整已验证结果，不附带任务查询文本或凭据；顶层未知回执字段（例如意外回显 task/token）被拒绝，不能悄悄导出。文件本身包含记忆内容，应自行保护；它不是完整备份或永久有效的快照证书。预览不追踪后续数据库修改，需要新的显式查询取得当前结果。

## 证据范围

Node 测试执行实际发出的浏览器 JS，用合成 DOM/HTTP 和等待屏障验证边界。真实 Chromium/当前控制台/托管 PostgreSQL 集成由 `test/personal-recall-browser-fixture.mjs` 驱动 `test/personal-recall-browser.py`，前后比较记忆、事件、Agent、文档及整理任务表指纹，验证没有应用数据写入。

测试用的用户动作和记忆均为合成输入，不是用户实际模型会话或模型质量指标。阶段证据及未完成项见 `docs/reviews/recall-preview/README.md`，实际 CI/独立复审按最终完整提交记录于 PR #20；文件存在不代表测试执行成功。
