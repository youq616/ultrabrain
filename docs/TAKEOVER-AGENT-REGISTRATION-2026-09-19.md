## 本轮设计边界

新增 `src/client-agent.mjs`，由 `deliverCapture` 和 `deliverDocumentImport` 共用。每次查询最多 16 页，每页最多 100 个登记；超过边界拒绝而不是猜测不存在。一次注册冲突最多再做一次同样受限的查询，因此整个交付最多 32 页、最多一次注册写请求。现有 metadata 不用于授权、不被重写；不缓存跨调用身份。分页是现有服务端 live offset 协议，不宣称快照隔离；并发新增造成的遗漏由服务端 revision-zero CAS 拦截，仍可能安全失败。

capture 预检增加 `ultra_agent_list`，只读 profile 的必需工具不扩大。未新增服务端工具或迁移；现有显式 `ultra_agent_register` 的元数据更新语义不变。不把错误的 source、畸形列表、未知错误、身份漂移或仍查无标签的冲突视为成功。拒绝发生在发送前；撤回不能撤销已发送请求或已入库数据。
