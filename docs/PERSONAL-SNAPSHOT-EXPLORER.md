# 快照记忆浏览器

接续本地快照核验模块，解决单份已核验快照不能逐条浏览的问题。管理台中打开“核验／对照本地快照”，选文件并通过内部一致性核验后，点击“浏览已核验快照”。浏览一份文件不要求提供第二份；有两份时可明确选择左右一侧。它不是独立离线安装程序：管理台及固定静态脚本仍需加载。

## 完整流程

浏览索引有独立同意，打开面板不显示条目。勾选后点击“筛选／读取索引”，本地遍历已核验文件全部记录，包含候选、启用、归档、所有项目和文档片段，不限于当前服务器搜索页。索引只显示 ID、类型、状态、重要性、项目、Agent、来源类别、版本与更新时间，不显示正文、来源说明、内容指纹或派生引用。

点击“查看此条本地记录”才显示该条完整 JSON，以纯文本展示，保留原正文及元数据。翻页、修改条件或关闭浏览会清除正文。这个动作不读取服务器最新版本；没有编辑、启用、导入、恢复、剪贴板、下载或模型操作。原有快照对照/差异清单入口保持独立。

## 筛选、排序和分页合同

所有条件用 AND 组合。状态、类型、重要性、来源类别、Agent 为精确匹配，留空不限。项目范围为所有项目及全局、仅全局、仅指定项目；精确项目不包含全局。类型允许最多32字节小写英文字母/下划线，Agent和项目最多96字节英文字母/数字/下划线/连字符。

正文查询为区分大小写的连续文字匹配，保留空格、换行与字符，不分词、不正则、不语义匹配，也不搜索 provenance/derivation 等元数据。空查询不限制正文；最多4096 UTF-8字节，拒绝 NUL 及不完整 Unicode。条件无效整体拒绝，不显示旧结果，不回显关键词或原始异常。

默认 ID 升序，可改为更新时间、创建时间或重要性降序；并列统一按 ID 升序，比较不依赖系统区域排序。每页20条；计数基于全部匹配记录，不是这一页。最多1000条的原文件限制保持。空文件或无匹配明确显示0，不伪造分页。非整页偏移、负数、超上限和已越界页拒绝；页末不会重复显示上一页。

共享 `queryMemorySnapshot` / `readMemorySnapshotRecord` 只接受本模块实际核验产生的不可变句柄。查询返回深度冻结的元数据页，查询文字不附在返回对象中；详情返回冻结的原记录，不复制或改写它。这是本地数据句柄，不是来源认证或服务端权限。

## 撤回和隐私

筛选/排序改变后清除旧索引及正文，不自动搜索。切换左右文件时撤回浏览同意，需重新勾选。关闭浏览清除条件、索引、正文和浏览同意，但保留独立核验结果。撤回核验同意、更换文件、重新核验、取消、导航、刷新、锁定或写操作使浏览整体失效；未保存编辑草稿及原未确认请求不被接管。

父核验模块通过同步生命周期回调清理浏览内容，每次查看和翻页也直接检查当前核验句柄、实际文件、来源、会话、导航版本、busy/pending、面板可见性、浏览同意和精确筛选选择。安全不只依赖DOM观察器；已移除页的旧按钮也不能展示旧正文。浏览同意和两文件比较同意相互独立。

文件、正文查询和条目ID不传给数据API，不写浏览器持久存储，不产生下载；只允许加载固定静态脚本。索引本身仍包含私有元数据，内容不自动脱敏。清除引用不等于浏览器内存安全擦除；不防御同账号恶意脚本或被完全控制的浏览器扩展。

文件时间、状态、Agent和拥有者标志均为快照自述。内部一致性不是签名、所有者/真实性证明、实时数据库状态或恢复方案。原始数值语义及非有限数拒绝继续沿用快照合同。没有更改数据库模式、认证、MCP、依赖锁或模型设置。

## 验证入口

`node --test test/personal-snapshot-explorer.test.mjs test/personal-snapshot-explorer-ui.test.mjs` 覆盖54项纯合同和33项实际脚本/合成DOM检查；新固定静态路由另在控制台测试中检查。Linux与Windows可移植套件保留全部旧测试并追加本模块。

`test/personal-snapshot-explorer-integration.mjs` 在明确允许写入的一次性PostgreSQL中准备0/44/45条实际导出，包括三种状态、两个项目、两个Agent和一条真实文档片段；随后运行真实Chromium，Python独立计算筛选/排序/分页预期，浏览阶段须零数据HTTP/下载，六张表前后指纹相同。准备阶段确实有合成写入，不称全程只读；不调用外部模型。

`test/personal-snapshot-explorer-local.mjs` 是可选真实浏览器夹具，但使用合成存储适配器和手工构造文件，不是PostgreSQL或用户部署证明。最终SHA的实际CI和独立审核结果记于PR #20，不以定义的测试替代已执行结果。
