# 0.7.0-alpha.1 验收范围

结果绑定实际提交与 CI，不以本文件代替运行记录。

新增事实集成检查通过真实 remember、forget_fact、原生 recall、PostgreSQL 与 MCP dispatcher 验证旧事实未自动获得来源信任、指纹/CAS/重放、源版本变化、事实变化、来源有效期、私有来源、原生撤回和当前/历史隔离。自动来源登记采用明确声明的受控原生 insertFact 结果；不代表真实提取模型质量。

Agent 检查验证事实/页面联合字节预算、无来源/跨源/无效事实拒绝，以及原有未启用事实路径不变。HTTP 检查包括读写权限、跨 source 拒绝、资源撤回后的事实隔离和带 --facts 的真实事件桥子进程。

CI 增加从 0.6.1 提交 b46c067f0ef110900af7fe8bb2334b4a9c509c3c 开始的旧数据升级，保留前五个基线。旧应用写入原生事实后才执行候选迁移；验证原生数据指纹不变、旧事实仍无虚构关联、显式 history 可用。备份恢复纳入 fact_evidence 与 fact_evidence_events。

上游四个锁定提交和旧迁移保持不变。默认仍托管本地 PostgreSQL，不新增远程 SQL 或主机命令执行接口。本版尚未认证真实长会话模型准确率、所有原生事实消费接口统一治理、旧 facts 自动无损来源迁移、全部客户端原生 Hooks 或用户服务器部署。
