# 本地重复记忆审阅面板

在既有个人记忆管理台中，选择“核验／对照本地快照”，完整核验一份或两份文件后，新增的“审阅重复记忆”入口可审阅所选一侧的重复组。打开面板不会扫描；需要另行勾选扫描同意并点击“扫描重复组”。每次只扫描一份已经核验的文件，不比较两份文件之间的正文。

## 行为与范围

判定标准沿用既有离线 `duplicates`：原文完全相同，不进行大小写折叠、空格裁剪、换行转换、Unicode 归一化或近义匹配。扫描包含文件中全部项目、状态与来源类型；同文不同项目、可见性、候选／启用／归档状态仍属不同记录。内容指纹用于展示，不作为正文相等的唯一依据。

面板列出重复组、组内成员和差异字段。重复组与组内成员各自每页最多20项，支持前后翻页，所有结果均可到达。桌面使用两个有高度限制的独立滚动列表，窄屏改为单栏。当前实现沿用原快照的1000条、8 MiB紧凑内容与16 MiB文件限制，不以当前页代替完整扫描。

扫描同意只授权查看编号、指纹、项目、状态等私有元数据。查看单条完整记录还需第二个同意开关和对该记录的明确点击；正文、来源说明、引用等只以纯文本 JSON 展示，绝不作为 HTML 执行。翻页或改选组会清除已显示的全文和全文同意；不载入编辑草稿，不查询数据库当前版本，也不输出报告下载。

“额外出现次数”是组内成员数减一的合计，**不是可删除数量**。即使差异字段为空，仍未证明完整引用语义、权限、来源和归属相同；不能据此自动选择保留哪条。文件自述的所有者范围与来源不是当前登录身份认证或真实性证明。

## 清理与失败语义

改变所选文件、撤回父级核验同意、重新核验、锁定、导航或进入其他工作区时，父级同步清理回调会撤下重复报告和正文。切换左右侧或撤回扫描同意需要重新明确扫描。用户取消会中止后续交付，不会删除文件、撤回已经发生的本地读取或修改服务器任务。

每次异步扫描和页面／条目操作均再次检查父级文件句柄、选择、页面、会话及同意。旧页面分离出来的按钮不能显示过期正文，也不能清空新的成功结果。尚未扫描、失败、取消与完整扫描后的零组报告是不同状态；错误不伪装成空库或部分成功。

关闭面板保留父级已核验文件和独立编辑草稿，但释放面板自身的结果引用。清空引用不保证物理内存安全擦除；父级还持有所选文件的完整内容，撤回核验才清理父级。此工具不保存浏览器存储或自动持久化审阅状态。

## 共享实现

`src/personal-snapshot-contract.mjs` 现在承载唯一的 `inspectMemorySnapshotDuplicates` 与字段常量。原 `src/snapshot-duplicates.mjs` 保留为兼容导出，不复制算法。浏览器与既有 Node API 共享同一个弱集合验证边界，拒绝拼造或复制的核验句柄；原公开路径与响应格式不变。

原算法中的 Node专用定时器和字节计数改为跨环境的 `setTimeout` 让步与现有 `TextEncoder` 字节函数。每32条进行检查与让步，单个大型重复组的成员投影也会让出事件循环；取消或权限变化可被观察。界面复用父级已经加载的 `/snapshot-contract.mjs`，不会创建第二个有不同弱集合身份的合同模块。

控制台仅增加一个固定静态脚本地址 `/snapshot-duplicates-ui.js`，原 Host/Origin/CSP/token 政策和 API 路由不变。没有新增数据库表、迁移、MCP工具、写权限或模型配置。此面板不属于私有 CLI tarball 的网页资源；完整管理台源代码随源码归档提供。重新构建 CLI 包仅用于验证共享算法移动没有破坏既有离线入口。

## 验证入口与证据边界

`node --test test/personal-snapshot-duplicates-ui.test.mjs test/personal-snapshot-duplicates-shared.test.mjs test/personal-snapshot-duplicates-review.test.mjs` 覆盖实际脚本的合成 DOM、完整文件句柄、分页、撤回、迟到结果、原型形态文本与真实 Node HTTP 静态路由。合成 DOM 不等于真实浏览器；HTTP 路由测试使用合成数据库适配器。

`test/personal-snapshot-duplicates-browser.py --offline` 加载真实 Chromium、完整页面、CSS与七份生产脚本；登录上下文为合成，透明地通过 Python SHA-256 计算摘要，因为不透明离线页没有 WebCrypto.subtle。分组结果由独立 Python 原文分组作为测试预期。它不是在线 HTTP/CSP 或用户设备部署证明。

`node test/personal-snapshot-duplicates-http-browser.mjs` 是真实控制台 HTTP/CSP 版本，在正常浏览器中使用生产 WebCrypto，数据库仅模拟启动和登录初始列表。测试检查审阅阶段没有数据库请求或数据上传。该入口已追加到已有浏览器 smoke CI，原步骤与工件保持不变。工作流存在不表示已经运行；本轮环境的实际执行范围以审核记录为准。

本模块仍是开发候选。上轮重复审计和本轮界面均尚未远端发布；真正的独立第二代理审核与最终远端 CI 未取得，不合并主线、不部署用户主机。
