## 规则与自审

发送前记录此前是否存在未知交付，校验器仅在验证合同后返回内部结果类别。既有未知交付加无结论响应时，保留同一个请求对象、原JSON、原任务ID与未知标志；清除旧观察并禁用直接再次提交。last_processing_outcome是已验证结果的类别，不是授权或原回执。状态核对不自动结束请求；终态仍需勾选、确认及新一次只读查询。有效同任务处理结果可正常确认。终态观察不是与将来的其他操作原子绑定，不提供外部调用或费用exactly-once。

实现者自审检查连续三种无结论响应、处理与排队状态、错误合同、相同输入重试、实际结果确认、终态二次查询，以及取消/导航/会话/来源/同意在等待期间改变。只改web/personal/app.js的生产代码；没有后端、SQL、迁移、权限、MCP名称、锁文件、用户配置、qbrain或服务变更。此前测试清单和全部集成阶段保留，新增测试为追加。
