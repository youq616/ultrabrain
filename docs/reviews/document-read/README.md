## 缺口和修复

旧读取只检查响应正文与响应自身的哈希，不绑定所选文档／来源／不可变元数据；同页多个请求共用 documentEpoch 和 documentOriginal。可能展示错误文档或被迟到响应覆盖，预览缓存也使后续下载不再检查服务端可见性。

现在读取前冻结选择；核对 source、ID、不可变元数据、版本状态以及有界规范 Base64／严格 UTF-8／BOM／所选 SHA-256。每次明确下载重新读取，使用局部已核验字节；新选择、取消、导航、锁定及明确写入使旧请求失效，包括哈希计算期间。添加清除／取消按钮，合并原来 active 与 archived 分支重复的读取按钮逻辑，保留两种状态的原文下载。
