## 完整模块

新增独立 ultrabrain-snapshot 命令及 dist/snapshot.cjs 库，完整支持 inspect、
compare、page、record。复用已验收的快照校验/比较/筛选；共享合同仅导出两个
现有纯校验函数，不改原语义。支持每份输入的可选 SHA256 固定，默认仅元数据，
record/include_text:true 才交付正文/来源说明/派生结构。无 SDK、在线 Profile、
模型、来源跟随、扫描、写入或恢复。文件及字节 API 均有明确许可与撤回围栏。
详情见 ../../CLIENT-SNAPSHOTS.md。

实际文件读取拒绝链接/UNC/特殊路径及非普通文件，检查大小、描述符/路径及父
目录身份、mtime/ctime，所有路径关闭句柄并在清理后检查授权。它不是原子文件
系统事务，网络挂载的 OS 行为也不受模块限制。相同 source 标签不认证同一主体；
结果恒为 identity_verified:false、truth_verified:false，不把差异当恢复计划。
