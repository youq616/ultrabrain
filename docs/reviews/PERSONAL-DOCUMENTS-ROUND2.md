## 修正与边界

模型调用准入使用与归档/取消相同的短事务及主体锁，重新核对 job 状态、租约 ID/到期、原文版本/指纹/归档状态和取消信号。该适配器的异步网关加载移到准入前。只有检查通过才在持锁期间**启动网关调用**，不等待模型响应；归档在准入前先完成则不会调用，已经启动的 SDK 调度/网络/远端处理仍不能承诺撤回，归档继续阻止其输出落库。若启动后事务确认丢失，返回 personal_commit_unconfirmed，保留 processing，由明确恢复处理，不自动重发。测试单独覆盖归档、取消、来源变更、租约过期、AbortSignal、模型等待不占数据库锁，以及调用后事务确认失败。

文件导入先通过当前主体的 ultra_agent_list 查询已有标签，已有标签完全不修改；确认不存在时才登记新的 custom 标签。查找最多16页（每页100条），异常/不前进游标或超出窗口明确失败，不以猜测缺失覆盖元数据。每个等待后继续检查本地授权/取消；最终写入前再次验证身份。目录查询期间发生权限撤销不会开始写入。

CI 另发现浏览器测试自身的问题：Playwright evaluate 对返回函数的赋值表达式会调用该函数，恢复 File.prototype.arrayBuffer 时触发 Illegal invocation。改为不返回函数的代码块；没有删减撤销同意断言。使用原配置 Chromium 在 about:blank 上复现旧错误并验证修正，不改网络管理策略。完整浏览器文件/API 测试仍须当前 SHA 的 GitHub CI，不冒称本机已绕过管理员阻断。
