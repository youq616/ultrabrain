# 跨快照重复变化审阅界面

管理台“核验／对照本地快照”中，明确选择左、右两份文件并完成整个文件核验后，可打开“对照两份文件的重复变化”。只提供左侧时入口不可用。打开不执行比较，必须另行勾选同意并点击“比较重复变化”。此前的单文件重复审阅和 CLI／文件／字节 API 保持原有入口。

本面板直接调用现有共享合同 `compareMemorySnapshotDuplicates`，没有另一套分组、身份或完整性规则。两份文件逐一完整核验；每份仍限制1000条、8 MiB紧凑内容和16 MiB文件。失败、取消、尚未比较与完整比较后零组是不同状态，不以部分结果或空统计掩盖错误。

## 四类筛选与两侧核对

比较范围包含两份文件的全部项目与全部状态。只认正文完全相同，不忽略大小写、空白、换行或Unicode形式，不作近义匹配。选择“全部类别”“仅左侧重复”“仅右侧重复”“两侧重复且有变化”或“两侧重复且相同”筛选已完成的结果；筛选和分页不再读文件、不重新执行比较，也不向服务器查询。

组列表每页最多20项。点击一组后，将该内容组两侧成员ID合并为唯一索引并按ID排序，每页最多20项，所有成员均可查看。左右各1000条且ID不重叠的极端情况可展示完整2000项索引。被选择的组有可见标记和 `aria-pressed` 状态；切换类别清除原组选择。

成员卡片显示该ID在该内容组的左右侧元数据，以及共有成员的变化字段名称。对侧只有一条同文记录时仍显示“单条同文记录，未达到重复条件”，不会混同于没有记录。“该内容组内仅左／仅右”不是整个文件中的ID新增或删除证明；同一ID改变正文可能出现在另一组。左右输入顺序不代表时间先后，相同来源标签不证明同一所有者。

**本面板没有正文入口或报告下载。** 它只展示指纹、字节长度、ID、项目、状态、可见性、版本、来源类型及变化字段名；来源说明和结构化引用的原文不会显示。字段相同或不同都不证明来源有效、真实性、可替代性或安全合并。所有文本用 `textContent`，不执行文件中的HTML。元数据本身仍可能敏感，不能公开。

## 生命周期与边界

必须使用父级完整核验持有的原始句柄，不能传入任意结果或跨文件借用授权。比较期间及结果操作前核对同意、文件选择、会话、来源、视图、导航版本和busy/pending状态。换任意一份文件、撤回父级同意、重新核验、锁定、导航、切换其他审阅入口时，同步清除该面板的结果和选择。撤回本面板同意或关闭会使未完成计算的交付失效；迟到错误不能清空一次较新的成功结果。

分类筛选值也是显示状态的一部分。程序只设置筛选值而未发出change事件时，旧翻页动作会拒绝继续展示，而不是在新标签下保留旧组。分离出来的旧组按钮不能切换旧内容或影响新结果。

打开本面板会清除其他本地审阅入口已显示的全文，但保留父级已核验文件和独立编辑草稿。关闭不删除文件，不取消服务器任务，也不保证物理内存安全擦除；父级仍持有完整已核验文件，撤回父级核验会清理其引用。已有全文件核验同意与本次跨文件比较同意相互独立。

没有新增数据库、迁移、MCP操作、模型调用、写权限、网络数据请求、自动轮询、删除或合并功能。控制台仅增加固定静态脚本路由，原Host/Origin/token/CSP保持不变。网页资源来自管理台源码，不在客户端CLI tarball中；本轮没有宣称新CLI包或生产部署。

## 验证入口

`node --test test/personal-snapshot-duplicate-compare-ui.test.mjs test/personal-snapshot-duplicate-compare-review.test.mjs` 使用生产页面脚本、规范快照和合成DOM，覆盖64项；不是实际浏览器声明。其中包括真实Node HTTP静态路由和副作用检查。旧的跨平台测试命令原样保留，新文件作为独立步骤追加。

`node test/personal-snapshot-duplicate-compare-http-browser.mjs` 启动生产控制台HTTP/CSP，使用合成数据库仅回应启动与登录列表，通过Chromium读取明确选择的本地文件，检查四类筛选、两级分页、单条保留、原文不披露、取消、来源不同、文件损坏、390像素布局及没有数据请求。真实在线结果须以实际执行记录为准。

`python test/personal-snapshot-duplicate-compare-browser.py --offline` 是不同的证据模式：完整页面、CSS及八份生产脚本，但合成登录并使用Python SHA-256桥接，因为不透明离线页没有生产WebCrypto。其16项成功不能替代在线HTTP/CSP验收。运行概览和单文件重复审阅的既有浏览器夹具均更新为加载完整八份脚本，不删旧检查。

本轮单独复查发现并修复筛选值静默变化后的旧页残留问题，两个首败断言已留档。自查、测试算法或CI不是第二审核代理；最终提交仍需独立代理复审，保持草稿、不部署。执行结果及首败说明见 `docs/reviews/snapshot-duplicate-comparison-ui/README.md`，远端结果以最终PR的实际工作流为准。
