# 个人文档模块：完整操作与验收范围

本模块面向个人 Linux 记忆管理台，把已有导入、回执、原文读取、队列和归档连接成一条可操作且有端到端验收的流程。本轮基于 `2ed1e2a23715c8cbe6bf3b95225c9dd81116c96a`，实际发布与验证结论以 PR #20 对最终提交的记录为准；仅有本文或用例文件不表示验收通过。

## 完整流程

打开「导入文档」只查询当前本机所有者的文档元数据，不读取正文。列表每页20条，可以选择全部、使用中或已归档；切换状态回到第一页，过滤在服务端执行。列表是有界实时页，可能随并发变化，不是数据库快照、全库数量或完整备份。

在表单明确选择 UTF-8 的 TXT、MD、JSON、CSV 或 LOG 文件（1–131072字节），核对项目并同意后才导入。BOM、换行及原始字节保留，重复提交原事件不会重复导入；不同事件的相同有效文件遵循现有去重合同。PDF、图片、Office转换、OCR、文件夹扫描及自动监控不属于这个文本模块。

在通过校验的文档卡片点击「查看原文」或「下载原文」，均重新读取当前授权下的文档并核对ID、不可变元数据、严格Base64/UTF-8和原指纹。预览按纯文本展示；下载直接使用已校验字节，不经过文本重编码。新读取取代旧读取，清除预览、导航、锁定或写入操作使旧读取失效，迟到响应不能恢复旧内容或发起旧下载。取消不撤回已到达服务器的查询，也不能追回已触发的下载。

「排队整理」只把整文件按UTF-8边界切为不超过32KiB的片段、保存私有候选并建任务，操作本身不调用模型、不自动激活候选。模型配置、调用授权、费用及模型结果质量属于现有整理模块的独立范围。归档保留原文，退出当前处理范围、使派生内容失效并阻止未完成任务提交；不是物理擦除。已归档卡片仍可核对和下载原字节。

## 列表是选择入口，不是任意JSON容器

本轮补齐列表入口：在展示任何卡片或允许导出之前，整页验证返回来源、字段集合、条目数、唯一ID、元数据、非负片段数、所选生命周期过滤和精确分页偏移。含正文、内部主体字段、重复条目、混入错误来源或末条不合法时，整页拒绝；不会部分显示、把异常响应当成空库，或遗留已启用的下一页按钮。

已通过的元数据页、数组和各行冻结后才交给读写按钮。分页请求也冻结会话、来源、视图、状态选择和偏移；这些条件改变后，旧成功或错误响应不能覆盖新页面。来源和会话由已有控制台连接确定，不接受用户用文档ID改变授权主体。

「导出当前页」只导出这一页已验证的元数据，不带原文字节、控制台令牌或完整备份保证。失败列表没有导出权限。过滤、刷新、读取和导出不会自动修改记忆。

## 故障与重试

记忆和文档写入继续使用既有冻结请求及原事件重放。HTTP状态和业务回执矛盾、响应缺失或字段不匹配时，保留待确认请求，而不是假称没有写入。明确重试仍需原选择和同意；不生成新事件绕过未确认状态。无关草稿不因审核、文档或任务操作被清空。历史事件确认不等于记录现在仍处于当时状态。

校验只能验证当前响应与合同/已选择信息一致，不能抵御一个同时伪造列表和正文的恶意服务器，也不是磁盘持久化或内容真实性证明。列表JSON解析之前的网络总内存不由本次序列化大小检查限制。排队时浏览器没有片段字节预映像，片段哈希仍只校验形状；实际字节正确性由服务端及合成集成核验。

## 可复现验收

`node --test test/personal-document-module.test.mjs` 运行实际页面脚本与明确模拟的DOM/HTTP；它不等于浏览器或数据库证明。

`ULTRABRAIN_TEST_ALLOW_WRITE=1 bun test/personal-document-module-integration.mjs` 只应在明确授权的隔离测试数据库执行。它创建独立合成source和23个列表夹具（21个使用中、2个已归档），启动真实控制台和Chromium，再从UI完整执行分页、过滤、文件导入、预览、原字节下载、片段排队、归档及元数据异常拒绝。独立数据库断言最终只新增1文档、1片段、1零尝试失效任务及3个用户事件，且无关草稿没有入库。

上述整模块验收追加在现有预览/纠错/回执/读取套件后，未替换原测试或n8n/历史升级。CI在启动运行环境前用 `git archive HEAD` 保存精确跟踪源码，产物不含运行时凭据、数据库、vendor工作目录或未跟踪用户内容；其子模块内容仍由现有锁文件定义。报告、截图和独立复审必须关联最终提交，不能沿用父提交结果。

## 独立审查后的验收补强

文档元数据日期必须采用服务端 JSON 的 UTC 毫秒格式，并能解析后按原样格式化；简称日期、非法日期被自动进位、其他时区拼写均整体拒绝，不启用卡片或导出。实际归档验收不仅计数文档、记忆与任务，还计数 `personal_document_fragments` 并通过同源同主体的关联查询，检查文档、片段记忆、任务、字节范围、原文和指纹完整保留；缺失关联不能被内连接过滤掉而假报成功。独立审查原发现、首败及修正门槛见 `docs/reviews/document-module-finish/`。
