## 3. 产品目的与架构蓝图

优先交付个人 Linux Agent 记忆服务。GBrain 为锁定的 PostgreSQL-native 业务引擎，保留页面、事实、版本、纠正、召回、图谱、技能和任务；Ultrabrain 提供个人所有权、候选/审核、客户端、管理台、可靠交付、部署/恢复等产品层。OpenViking 是按功能吸收的参考，不宣称双方全部功能等价。

- 一个项目管理的本机 PostgreSQL 作为事实/记忆存储；客户端 outbox/journal 是交付日志，不是第二套事实库。
- 服务端从认证推导 source/principal；agent_id 是标签，不能作为身份凭据。workspace、destination、实例 pin 与单次同意分别核验。
- 原文采集、队列交付、模型整理、人工确认与上下文召回分层，观察或模型输出不自动成为用户确认事实。
- 读取不自动启动模型；显式授权、取消/撤回、不可变 event_id 重放和回执未知状态保留真实语义。
- 数据库迁移不可改写；修复用追加迁移。旧无归属数据不猜测所有者。上游完整 SHA 锁和独立 Windows qbrain 项目保持不变。
- 个人管理台默认本机 loopback，远程查看走明确 SSH 转发。服务安装、激活、就绪、恢复的各自合同不能互相替代。

架构/接口说明：[个人核心](PERSONAL-CORE.md)、[语义记忆](SEMANTIC-MEMORY.md)、[治理](MEMORY-GOVERNANCE.md)、[受治理事实](GOVERNED-FACTS.md)、[Agent 接入](AGENT-INTEGRATION.md)、[可靠性](RELIABILITY.md)、[功能覆盖](FEATURES.md)。
