# 0.6.1-alpha.1 验收范围

具体结果应绑定提交和 CI 运行，本文件不预写成功结果。

本轮接续尚未合并的 0.6.0 资源治理及身份事件桥，并追加：

- 0007-review-dependencies：引用依赖索引、直接/多层变更传播、循环去重，以及对旧 active source_quote 的保守重审。
- policy 查询：按当前数据库时钟检查引用链；来源过期不必等待一次写操作才退出当前检索。
- vector-plan / vector-upgrade / vector-recover：主机独有的 SQL 扩展计划、维护、备份、事务更新及中断恢复，无 MCP 数据库管理员接口。

引用依赖测试在真实 PostgreSQL 上覆盖多层失效、撤回、改用另一来源、软删/恢复、物理删除、自引用、循环引用、并发审核与来源更新、时间有效性。原生治理/HTTP/摘要/断点/队列回归继续执行。

pgvector 测试创建单独的临时集群，检查真实 SQL 版本转换、应用连接拒绝、注入 SQL 错误后的回滚和进程强制退出后的恢复。使用当前锁定的动态库，不宣称认证旧库 ABI。所有备份只含合成数据，测试不会上传数据库内容或凭据。

升级矩阵增加 0.6.0 提交 32f97e8d45b312980ce6ab1784cf316feddd698e，保留 0.3.0、0.3.1、0.4.0 和 0.5.0。旧版引用审核作为真实旧数据建立，再检查新迁移会保留原文并标记重审。0001..0006 的字节及四个上游锁定提交保持不变。

备份恢复增加 review_dependencies 指纹。本轮没有真实模型语义质量认证、全量原生 facts 删除传播、原生客户端 Hook 全覆盖、附件协调备份或生产部署的验收结论。
