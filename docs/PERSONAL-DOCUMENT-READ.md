# 管理台文档读取与下载

本阶段扩展的是明确点击“查看原文／下载原文”后的读取路径；接口仍是既有 document_read，仅发送所选文档 ID。没有扫描文件、写入记忆、自动下载或调用模型。

## 请求与内容绑定

读取前冻结卡片上的文档 ID、文件名、格式、大小、SHA-256、BOM、Agent 标签、项目、创建时间及版本状态。响应必须来自当前 source_id，且不可变字段与所选文档相符。标签按现有文件名约束检查，不允许路径和控制字符。Agent 标签不是软件身份认证。

正文在解码前校验标准 Base64 的形状和精确长度，解码后再核对规范编码、字节数、严格 UTF-8、BOM 和所选 SHA-256。原文最多 128 KiB；这是应用层正文解码限制，不是对 response.json() 之前所有网络响应内存的总量保证。不能把另一份“正文与其自身哈希一致”的文档显示在本次所选标题下。

允许卡片呈现后发生的合法归档：不可变字段不变、版本不回退，同版本的状态与归档时间不能矛盾；已归档卡片不能读回 active。预览标题使用本次已核验响应的状态，不用旧卡片假称仍启用。响应仍是读取时快照，不保证此后没有新操作。

BOM-only、NUL-only、空白和真正的 U+FFFD 都是可以保留的原文，不以“能否送入模型”代替原文字节合同。预览用 textContent，不渲染 HTML；预览省略开头 BOM，下载使用未重新编码的原始字节，保留 BOM 和换行。

## 最新选择、清除与下载

每次新读取立即清除旧预览并取消旧等待。请求返回、哈希完成和展示／下载前均核对会话、来源、导航及最新读取序号；即使取消没有阻止服务器返回，旧内容和旧错误也不能覆盖新页面。刷新、导航、锁定管理台或开始明确写入会使旧读取失效。

“清除原文／取消读取”清空当前页面原文并阻止未完成请求展示或触发下载；不删除服务器文档，不撤回已到达服务器的请求，也不撤销已经触发的下载。文件选择器、文档写入 pending 和独立编辑草稿不受该按钮修改；原来的锁定行为仍清空编辑草稿。

每次下载都会重新调用 document_read，不复用预览缓存，因此先前读到过不构成以后下载的授权。一次下载使用本次核验的局部字节及标签，不依赖可能被并发读取改写的共享缓存。选择另一文档或取消未完成下载后，旧下载不应再产生文件。

## 验证与限制

`node --test test/personal-document-read.test.mjs` 执行实际页面脚本和合成 DOM/HTTP，包括忽略取消的迟到响应与延迟哈希；不等于真实浏览器。`test/personal-document-read-browser.py` 由已有隔离 PostgreSQL/Chromium fixture 在前面文档合成写入之后执行；新读取阶段前后五表指纹必须一致，不把前面有写入的阶段说成只读。

本校验是已公开合同一致性与客户端选择隔离，不是密码学认证、磁盘持久化证明或防同账号恶意脚本机制；恶意服务器若同时伪造列表及响应不在保证范围内。日期有效不证明时间真实。取消任务和模型整理的业务回执尚未扩展，本阶段不增加模型 exactly-once 或费用保证。最终提交的 CI 和独立复审结果记于 PR #20。
