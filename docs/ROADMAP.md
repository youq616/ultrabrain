# Ultrabrain 产品开发与验收计划

本计划采纳自动接入、项目续接、可靠采集、语义检索、事实治理、多 Agent 协作、数据生命周期、多模态与效果评测的完整建议。它不是“所有 Agent 都永不遗忘”的承诺。

架构不推倒重来：GBrain 继续提供既有页面、事实、图谱和检索；Ultrabrain 新增产品层与可靠性能力；PostgreSQL 仍为同机托管的唯一服务端数据库。客户端 outbox 是待交付事件的文件日志，不是第二套事实/向量数据库。OpenViking 按功能逐项吸收，不能把保留其源码 gitlink 说成已融合全部能力。

## 本次交付：0.3.0-alpha.1 的 P0 可靠性增量

| 项目 | 已写入的能力 | 验收与边界 |
|---|---|---|
| 可靠采集 | 私有文件 outbox、文件与目录 fsync、不可变事件与 ACK、断线补交、持久化退避、显式排除/脱敏回调 | 重启、事件冲突、丢 ACK、权限与篡改测试；至少一次，不宣称 exactly-once；成功入队之前的进程崩溃仍需执行框架配合。 |
| 项目检查点 | 独立项目目标、约束、任务、阻塞、下一步、递增版本、历史和幂等 event_id | 真实 PostgreSQL 并发更新只允许一个预期版本提交成功；这不是恢复任意进程堆栈。 |
| 有据的执行状态 | 区分 planned / in_progress / blocked / reported_complete / verified_complete | verified_complete 需要 host-only runner 的成功执行回执，校验 source/project/task/spec；回执只证明被选进程退出状态，不证明任意业务结论、远程部署或代码版本。 |
| 换会话续接 | AgentMemory 读取项目检查点，再扩展“继续开发”等查询并向生成回调提供项目摘录 | 不会自动读取未接入软件；不把记忆里的命令自动执行；项目摘录另有 4 KiB 上限。 |
| 项目遗忘 | 原子删除活动状态、历史、执行回执，保留内容无关 tombstone 防止事件重放复活 | 不删除独立页面、WAL、备份与未接入系统中的副本。 |
| 效果评测起点 | 可复用检索评测器，报告 recall、MRR、空证据准确率、禁用证据命中、延迟 | 当前 5 个真实数据库合成词法用例，不是长期语义质量排名；未调用付费模型。 |
| 历史缺陷修复 | CI 缓存前创建 0700 HOME；JSONB 双重编码修复；固定 public search_path 防止同名 schema 影子表 | 发现既有影子数据时拒绝静默切换；不自动合并或丢弃旧数据。 |

## 后续工作：全部保留，不伪装成完成

### P0 后续：适配器与证据链完善

- 提供 n8n、通用 HTTP/MCP 客户端及选定 Agent 框架的安装式适配器；身份与目的地从认证配置绑定，而非仅相信显示名。
- 把输入、工具执行、生成结果与持久化交付作为独立事件，支持执行框架 checkpoint / interrupt / resume。
- 增加独立的“原始会话已保存”和异步整理任务调度；当前 commit_session 仍同步调用原生提取，已独立返回 storage 与 extraction_state。
- 在执行回执中绑定 Git commit、工作树状态、构建产物和可信 CI/部署见证；不能把旧测试结果当新版本验收。
- 逐项验收 GBrain 原有 remember、纠正/撤回、时间语义、技能与图谱，补统一来源、有效期及置信状态。

### P1：语义组织与检索质量

- 真正的 L0/L1 语义摘要、原文引用、按内容 hash 失效、摘要模型版本；当前仍是明确标注的前缀摘要。
- 检索前的项目/时间/实体约束、查询规划、多轮展开、原文核对与低置信度返回。
- 针对指定模型的 tokenizer 与总上下文预算，分别报告元数据和证据开销；字节不能冒充 token。
- 真实用户同意使用的长会话标注集，检索和最终回答分开评分，测试更正、时间推理、无证据弃答、长跨度续接和成本。

### P1：多 Agent 记忆治理

- 稳定用户、Agent、项目和团队身份；清晰的个人私有与项目共享语义。
- 当前按 source 授权的检查点进一步支持项目级授权；目录受限和 delegated 客户端暂不开放新 metadata 工具。
- 对共享事实实现版本冲突、来源优先级、时态替代与人工纠错；优先复用上游，避免第二个事实引擎。
- 审计检索文本中的恶意指令、记忆投毒与越权泄露；untrusted 标记不是完整防御证明。

### P2：数据生命周期与多模态

- 记忆查询/纠正/导出界面、保留期、敏感信息策略、删除传播及备份到期策略。
- 附件与数据库协调备份，文件完整性与恢复演练；可配置静态加密/密钥管理。
- 图片、PDF、音视频、代码证据的原始定位与解析；保留页码、时间戳、文件版本。
- OpenViking 无损迁移器、公共接口/资源类型映射、兼容性验收。
- PostgreSQL 跨主版本迁移、新集群演练和明确恢复路径。现阶段仍拒绝直接跨主版本切换。

## 发布门槛

同一候选 commit 的单元、运维、真实 PostgreSQL、stdio/HTTP、项目冲突与证据、备份恢复、运行目录停启测试均通过，才能成为集成基线。语义质量必须另有模型与数据集证据。只完成某个阶段不等于两个上游全功能等价，也不等于已部署用户服务器。
